# Routrip

Aplicativo Android para criar um planejamento simples de viagem. O projeto foi desenvolvido em Kotlin e utiliza telas em XML.

## Funcionalidades

- Escolha do destino da viagem.
- Seleção das datas de ida e volta.
- Validação para impedir que a volta seja anterior à ida.
- Preferências de gastronomia, natureza e fotografia.
- Lista de atividades filtrada pelas preferências escolhidas.
- Definição da duração e do nível de dificuldade da atividade.
- Possibilidade de adicionar várias atividades ao roteiro.
- Bloqueio de atividades repetidas.
- Resumo com os dados da viagem e todas as atividades selecionadas.
- Retorno à tela inicial após finalizar o planejamento.

## Telas

1. Configuração da viagem.
2. Lista de atividades.
3. Detalhes da atividade.
4. Resumo da viagem.

## Tecnologias utilizadas

- Kotlin.
- Android SDK.
- Layouts em XML.
- AndroidX AppCompat.
- Material Components.

## Como executar

1. Abra o projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Conecte um aparelho Android com a depuração USB ativada ou inicie um emulador.
4. Selecione o módulo `app` e clique em **Run**.

O aplicativo requer Android 12 (API 31) ou uma versão mais recente.
